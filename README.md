# بشارة نور الدين مخملجي

صفحة دعوة عربية تفاعلية ثابتة، مصممة لتعمل على الهاتف وسطح المكتب.

## تخصيص بيانات الدعوة

عدّل ملف [`js/config.js`](js/config.js) فقط لتغيير اسم المولود، اسمه بالإنجليزية، تاريخ الميلاد والوزن المنقول من المرجع، الوالدين، تفاصيل الاستقبال، النصوص، الأدعية، الروابط، ومواقع الصور والوسائط. روابط الصوت والفيديو اختيارية؛ لا توجد ملفات صوت أو فيديو في الأصول الواردة.

## التفاعلات

تتضمن الدعوة شاشة فتح متحركة، عدادًا حتى موعد الاستقبال، روابط حفظ الموعد في تقويم Google أو Apple، ونموذج تأكيد حضور وسجل تهانٍ. تؤدي الاستمارة حاليًا إلى حفظ الردود والتهاني في المتصفح المحلي فقط لأن رابط واتساب أو خدمة تخزين مشتركة غير متاحة ضمن الإعدادات.

## النشر

يُنشر الموقع تلقائيًا على GitHub Pages عبر `.github/workflows/pages.yml` عند الدفع إلى `main`.
